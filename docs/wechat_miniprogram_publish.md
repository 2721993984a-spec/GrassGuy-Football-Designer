# 草皮哥平台微信小程序发布步骤

## 当前建议路线

第一版先做 `web-view` 小程序：小程序只负责入口，实际功能继续使用已经做好的 Streamlit 网页平台。

这样开发量最小，现有尺寸图、效果图、施工图、PDF 下载逻辑都不用重写。

## 你需要准备

1. 微信小程序账号。
2. 一个公网 HTTPS 平台链接。
3. 微信开发者工具。
4. 在微信公众平台后台配置业务域名。

## 我已经准备好的文件

```text
wechat-miniprogram/
```

这是微信小程序工程目录。

## 操作步骤

1. 先把 Streamlit 平台部署成 HTTPS 网页。
2. 打开 `wechat-miniprogram/config.js`。
3. 把里面的 `WEB_URL` 改成你的平台链接。
4. 用微信开发者工具打开 `wechat-miniprogram` 文件夹。
5. 把 `project.config.json` 里的 `appid` 改成你的小程序 AppID。
6. 在微信公众平台配置业务域名。
7. 预览没有问题后，上传并提交审核。

## 重要限制

- 正式小程序不能打开本地地址 `http://127.0.0.1:8501/`。
- 正式小程序需要 HTTPS 链接。
- `web-view` 要求网页域名在微信公众平台后台配置过。

## 后续升级

如果后面要做成真正原生小程序，可以再拆成：

- 小程序原生页面：输入尺寸、选择场地类型、预览图片。
- Python API 后端：负责计算、画图、生成 PDF。
- 文件服务：保存和下载 PDF。
- 员工账号：限制公司内部使用。

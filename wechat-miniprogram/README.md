# 草皮哥微信小程序套壳版

这个目录是微信小程序第一版工程，用 `web-view` 打开已经部署好的草皮哥足球场画图平台。

## 适用场景

- 公司同事在微信里像小程序一样打开工具。
- 继续复用现有 Streamlit 平台的计算、画图、PDF 生成能力。
- 不重写整套 Python 画图逻辑。

## 使用前需要准备

1. 一个已经可以公网访问的 HTTPS 平台链接，例如：

```text
https://grassguy-football-designer.streamlit.app
```

2. 微信小程序账号。
3. 在微信公众平台后台配置业务域名。
4. 用微信开发者工具打开本目录。

## 修改平台链接

打开：

```text
config.js
```

把 `WEB_URL` 改成你的线上平台地址。

## 注意

微信正式版小程序的 `web-view` 不能直接打开 `http://127.0.0.1:8501/`，必须是公网 HTTPS 域名。

## 原始模板尺寸

- 外包尺寸：34.50m x 20.20m
- 比赛区尺寸：31.50m x 17.20m
- 平台默认缓冲区：左右 1.00m，上下 1.00m；输入总尺寸包含缓冲区，比赛线自动内缩。
- 白线宽度：0.08m
- 罚球区圆弧：R4.50m，两段圆弧分别以球门上下两个门柱点为圆心
- 中圈：R2.25m
- 点球点：距球门线 7.50m
- 图纸平面球门开口/外伸矩形：深 1.00m，开口宽 2.34m
- 实际球门规格：3.00m x 2.00m
- 角球弧：R0.25m

## 后续自动套用比例

当五人制场地不是 31.50m x 17.20m 时，按以下比例自动换算：

- 罚球区圆弧半径 = 场地宽度 x 4.50 / 17.20
- 中圈半径 = 场地宽度 x 2.25 / 17.20
- 点球点距离 = 场地长度 x 7.50 / 31.50
- 球门外伸深度 = 场地长度 x 1.00 / 31.50
- 图纸球门开口宽度 = 场地宽度 x 2.34 / 17.20

## 画法要求

- 五人制罚球区使用“两个门柱点为圆心”的模板画法。
- 左侧罚球区：上门柱点为圆心画上四分之一圆弧，下门柱点为圆心画下四分之一圆弧，两段圆弧在场内用一段竖线连接。
- 右侧罚球区按左侧镜像处理。
- 不使用 7 人制和 11 人制的矩形罚球区加 D 形罚球弧画法。
- 点球点在场地中轴线上，左右各一个。
- 图纸上的球门开口按 2.34m 比例绘制；实际球门采购规格仍按 3m x 2m 记录。

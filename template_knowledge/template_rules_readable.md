# 草皮哥足球场图纸模板规则库

更新时间：2026-08-03

本文件根据 `reference_templates` 中的 3 份 PDF 模板整理。当前阶段用于指导平台画图逻辑，不直接替代专业施工蓝图。

## 已识别模板

### 1. 五人制足球场7.30.pdf

推荐用途：五人制常规横版模板，建议作为当前平台默认模板。

画幅：横版，约 1318 x 992，比例 1.329。

页面结构：
- 第 1 页：尺寸图。
- 第 2 页：效果图。
- 第 3 页：施工图。
- 左上角是绿色大标题。
- 主图在页面中上部偏右。
- 左下角是“草坪生产方案明细表”。
- 右下角是工程名称、图纸类型、制图单位、日期标题栏。

尺寸图规则：
- 外尺寸：25.30 x 17.80。
- 比赛区尺寸：23.30 x 15.80。
- 白草宽度示例：0.08m。
- 图中保留 R3.33、R1.66、R0.25 等半径标注。
- 白底黑线，尺寸文字靠近对应线段。

效果图规则：
- 草坪为深浅绿条纹。
- 足球标线全部为白色。
- 缓冲区边线也使用白色。
- 中线应落在浅色条纹中间，再向两侧依次排深浅色。

施工图规则：
- 中部有一条横向深浅绿带。
- A1-A6 为大号白字，从左到右排在中部条纹带内。
- B1 为粉色小补料编号，放在左侧补料区域。
- 绿色竖线表示接缝线，必须对齐卷材边界。

### 2. 五人制足球场1.14（4米）.pdf

推荐用途：五人制 4 米卷材细分模板，适合需要按 4m 整卷和端头补料拆分的场景。

画幅：接近正方形，约 989 x 992，比例 0.997。

尺寸图规则：
- 外尺寸：24.30 x 22.50。
- 比赛区尺寸：22.30 x 18.50。
- 标注中包含 2.00、1.00、0.50、5.73、R3.44、R1.72、R0.25、R0.08。

施工图规则：
- A1-A3 为大号白字，放在中间条纹带内。
- B1、B2 为粉色编号，属于深色卷材区域。
- B3 为粉色端头补料编号。
- 该模板不是 A1-A6 的横版规则，不能直接套用五人制 7.30 的编号逻辑。

### 3. 七人制足球场6.2.pdf

推荐用途：七人制或大型场地模板，施工图包含圆角/弧形端头补料。

画幅：横版大画幅，约 2735 x 1868，比例 1.464。

尺寸图规则：
- 外尺寸：53.00 x 35.00。
- 比赛区尺寸：50.00 x 32.00。
- 标注中包含 7.86、2.62、5.24、1.50、11.20、R4.36、R0.60、19.20、8.72。
- 罚球区按案例图显示：深 7.86m、宽 19.20m。
- 小禁区按案例图显示：深 2.62m、宽 8.72m。
- 罚球区外侧必须绘制 R4.36m 的 D 形罚球弧。

施工图规则：
- A1-A6 为白字，放在中部条纹带下半部或中部。
- B1-B7 为粉色字，放在中部条纹带上半部。
- B8、B9、B10 是端头短料/弧形补料编号，左右端头各出现一次。
- 示例短料长度：B8 33.16m，B9 29.10m，B10 21.59m。
- 绿色竖向接缝线需要随卷材宽度等距排布，圆角端头处按裁切形态收边。

## 全局规则

- 图纸固定三张：尺寸图、效果图、施工图。
- 草坪永远按深浅绿条纹输出。
- 条纹定位以中线为基准：中线在浅色中间，然后向外深浅交替。
- 缓冲区颜色与场地条纹保持一致。
- 效果图中的足球标线和缓冲区边线必须为白色。
- 施工图只保留接缝布和胶水两类辅材。
- 施工图编号和绿色接缝线必须绑定到卷材排布结果。
- 五人制罚球区统一按 `万盈镇沈灶小学足球场.pdf` 模板生成：两个球门门柱点分别作为圆心，画上下两段 R 圆弧，并在场内用竖线连接；右侧镜像。
- 五人制后续不再使用旧 `R3.33` 或 `R3.44` 整半圆画法；旧 PDF 只作为页面布局和历史尺寸参考。
- 五人制基础比例：31.50m x 17.20m，罚球弧 R4.50m，中圈 R2.25m，点球点 7.50m，图纸球门开口 2.34m，球门外伸 1.00m。
- 非同尺寸五人制场地按比例套用：罚球弧/中圈/球门开口按宽度缩放，点球点/球门外伸按长度缩放。

## 默认模板建议

第一版平台建议默认使用 `five_a_side_2026_0730_landscape`，也就是 `五人制足球场7.30.pdf` 的横版结构。

选择 4 米卷材模板时，使用 `五人制足球场1.14（4米）.pdf` 规则。

场地类型为七人制，或尺寸接近 50m x 32m / 53m x 35m 时，使用 `七人制足球场6.2.pdf` 规则。

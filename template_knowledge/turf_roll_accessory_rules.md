# 草坪整卷编号与辅材用量规则

来源模板：

- 草皮哥十一人制.pdf
- 七人制足球场效果图.pdf
- 万盈镇沈灶小学足球场.pdf

## 草卷编号

- 2米深浅双色草卷：一卷是两种颜色，施工图每一整卷只标一个 `A` 编号，例如 `A1-A8`，不要把同一卷里的深浅两半分别标号。
- 2米深浅双色如果边缘有剩余单色补条，补条统一标 `B1`，图上按实际补条宽度显示位置，生产明细表按实际补条宽度和实际面积计算，不再按 4m 整卷额外加量。
- 2米深浅双色编号字号要接近模板效果，不要过小；边缘补条 `B1` 可放到色带上方以免挤压。
- 4米分色草卷：按整卷颜色分别编号，浅色使用 `A`，深色使用 `B`。
- 2米深浅双色只用于五人制；7人制、11人制固定使用4米分色草卷。
- 浅色草卷统一使用 `A` 编号，例如 `A1-A6`。
- 深色草卷统一使用 `B` 编号，例如 `B1-B14`。
- 白草标线使用 `AW` 编号，第一版统一为 `AW1`。
- 施工图中间色带按从左到右编号，编号放在对应草卷色带中心。
- 生产明细表按“颜色 + 规格”分组：相同颜色、相同规格合并成一行，编号用连续范围表示。
- 4米分色模式下不足整卷宽的短卷按实际颜色进入 `A` 或 `B` 编号体系；2米深浅双色模式下边缘单色补条统一为 `B1`。

## 模板样例

- 五人制模板：浅色 `A1,A5` 为短卷，`A2-A4` 为整卷；深色 `B1-B4` 为整卷；白草 `AW1`。
- 七人制模板：浅色 `A1-A6`；深色 `B1-B7` 为整卷，`B8-B10` 为不同长度短卷；白草 `AW1`。
- 十一人制模板：深色 `B1-B14` 为整卷，`B15` 为短卷；浅色 `A1-A13`；白草 `AW1`。

## 接缝布

模板中接缝布按“米”计。第一版平台采用可解释估算：

接缝布长度 = 草卷接缝长度 + 白线安装接缝长度

其中：

- 草卷接缝长度 = `(按场地总长度方向排卷数量 - 1) * 场地总宽度`
- 白线安装接缝长度 = Shapely 标线几何总长度
- 最后再乘以页面设置的接缝布余量，并按整百取整显示，例如 619m 显示为 600m。

## 胶水

模板中胶水按“桶”展示，平台按固定模板比例自动计算。

第一版平台只显示桶数：

- 桶数 = `ceil(场地总面积 * 6 / 700)`

当前模板口径：约 700㎡ 使用 6 桶。
